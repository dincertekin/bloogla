Add a page in **Admin → Pages → New Page**. The editor works like a word processor: headings, lists, links, images, code and quotes are one click away.

To place the page in the sidebar, open **Custom fields** under the editor and add:

| Field     | Example         |
| --------- | --------------- |
| `section` | Guides          |
| `order`   | 11              |

Search at the top of the site finds text in every page.
